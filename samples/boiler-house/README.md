# Boiler house

Two shell boilers with their own combustion air fans, a shared feedwater set and deaerator, and dual-fuel supply. Enough equipment that one screen would be the wrong answer.

**93 tags** — 56 Bool, 2 Int, 35 Real

## Areas

- Boiler 1
- Boiler 2
- Feedwater and deaerator
- Fuel supply

## Import it

Tags → drop `tags.csv` on the upload panel, or click to browse.

The importer will report corrections on these, rather than applying
them silently:

```
STEAM HEADER PRESSURE
```
