## Open bug: React hydration error #418

The redesign caused it. React's Flight stream defers content above `MAX_ROW_SIZE = 3200`. The grid's second child arrived as a lazy row, and with no Suspense boundary a hydration that started before that row landed failed at the root. The size link is inferred: the lazy child and the empty fiber were observed, and the constant exists in React's source. The boundary's effect was measured.

| Page | Before the boundary | After | Live, old code |
|---|---|---|---|
| `/signup` | 4/7, 4/10, 7/12, 3/12, 5/16 | 0/20 | 0/7 |
| `/signin` | 2/7, 2/14 | 2/73 | 0/21 |
| `/reset/<token>` | not measured | 1/59 | 0/14 |

Live timing differs from local, so the last column is a weak baseline. Whether `/reset` is caused by this work is unknown, since its page was not redesigned. A clean baseline would be `main` built locally and run the same way.

When it happens React rebuilds the page and the form still shows. A failed load's log showed `data-theme` being cleared on `<html>` during recovery. Whether that flips a light-theme user's theme has not been checked.

## Traps that wasted time today

- **A test server outlives `TaskStop`.** The child `node` keeps the port and serves an old build from memory with new files on disk. Before starting one, check `netstat -ano | grep :3123` and kill that PID with `taskkill //PID <pid> //T //F`.
- **`timeout N npx next start` dies at N.** "Can't reach this page" then looks like page failures.
- **Git Bash rewrites `/signup` args into Windows paths.** Prefix with `MSYS_NO_PATHCONV=1`.
- **Headless Edge drops wheel events** if they are sent without waiting for the answer. A landing FAIL from this was false: with the answer awaited it scrolled 1500px.
- **A debugger hides the hydration race** (0 of 25 with it attached). To see the failing fiber, add a log at the throw in the built React chunk (`function rD(e){` in `.next/static/chunks/4bd1b696-*.js`).
- **Local `.next` still has that log in it.** Run `next build` before using it again. It is ignored by git and Vercel builds fresh.
